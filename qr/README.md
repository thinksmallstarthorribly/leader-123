# Leader 1-2-3 Primer QR Code

The QR code opens the **Leader 1-2-3 Primer** directly at:

> https://leader123.com.au/primer.pdf

| File | Intended use |
|---|---|
| `leader-123-primer-qr.svg` | Best for printed materials, banners, slides, and professional printing; it stays sharp at any size. |
| `leader-123-primer-qr.png` | Best for quick use in Canva, Word, email, or social graphics. It is 1800 × 1800 pixels. |
| `../primer.pdf` | The 17-page document reached when someone scans the code. |

Keep a clear white margin around the code, do not crop it, and avoid placing a logo or text over the code. Before printing in bulk, scan one printed test copy with a phone camera.
